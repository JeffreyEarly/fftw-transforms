# Licensing

Original FFTWTransforms source is licensed under MIT. The included `fftw3.h`
header retains its own permissive notice and is not relicensed by the project.

The FFTW library itself is GPL-licensed. FFTWTransforms distributes neither an
FFTW library nor a MEX binary linked against FFTW. Anyone redistributing a
locally linked binary is responsible for determining and satisfying the
applicable FFTW licensing obligations.
